# Security Policy

## Supported versions

Security fixes are applied to the latest release on the default branch.

## Reporting a vulnerability

Email **security@glasswarp.com** with a description, impact, and reproduction steps if possible.

Please do **not** open a public GitHub issue for sensitive reports. We aim to acknowledge within 3 business days and keep you informed of progress.

## Disclosure

We prefer coordinated disclosure. Do not publish exploit details until a fix is available or we agree on a timeline.
