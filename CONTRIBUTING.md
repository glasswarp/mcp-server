# Contributing

Thanks for your interest in Glasswarp.

## Issues

Bug reports and feature ideas are welcome via GitHub Issues.
Please include OS, SDK/MCP version, and a minimal reproduction when filing bugs.

## Pull requests

1. Fork the repo and create a branch from `main`.
2. Keep changes focused; include tests when behavior changes.
3. Ensure CI passes (`npm test` / `pytest` or the package build job).
4. Do not commit secrets, `.env` files, or personal API keys.

## Scope

This repository is **open source**. The Windows **host agent** and the Glasswarp
**platform** (signaling, console, billing) are proprietary and are not accepted
as contributions here.

Questions: [docs.glasswarp.com](https://docs.glasswarp.com) · hello@glasswarp.com
